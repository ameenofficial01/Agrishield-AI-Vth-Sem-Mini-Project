# AgroShield AI

**Explainable AI-Based Location-Specific Agricultural Pest Risk Forecasting and Early Warning System**

AgroShield AI is a frontend prototype for an agricultural pest risk forecasting platform. It is designed to help agricultural officers and extension workers view location-specific pest risk, forecasts, alerts, maps, explainable AI factors, and recommended actions.

> **Prototype Notice:** The current version uses demonstration/mock data. The machine learning model, FastAPI backend, and live environmental data integrations will be connected during later implementation.

---

## Features

- Frontend-only officer login
- Simple home page with quick pest risk check
- Location-based pest risk analysis
- State, district, crop, and pest selection
- Current pest risk score
- Low, Medium, and High risk levels
- 7-day, 14-day, and 30-day forecast views
- Interactive pest risk map
- Explainable AI preview
- Environmental factor contribution display
- Alerts and warnings
- Recommended preventive actions
- Responsive design for desktop and mobile
- Crop and pest image support

---

## Target Users

The primary users are:

- Agricultural Officers
- Agricultural Extension Workers
- Researchers and Analysts

Farmers are the main end beneficiaries of the pest warnings and recommendations generated by the system.

## Explainable AI

The current Explainable AI section is a frontend preview.

It shows factor contributions so users can understand why a particular pest risk is displayed.

The final system may later connect a trained machine learning model with an explainability method such as SHAP.

## Installation

Clone the repository:

```bash
git clone https://github.com/ameenofficial01/AgroShield-AI.git
```

Go to the project directory:

```bash
cd AgroShield-AI
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in the terminal.

---

## Build

To create a production build:

```bash
npm run build
```

The generated build files will be available in the `dist` directory.
